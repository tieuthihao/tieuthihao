TELC B1 REBUILD WITH PDF

Bản này sửa lỗi:
- Có PDF gốc để đọc đề trong web.
- Có data.js riêng.
- Có answer_key_template.txt để bạn tự nhập tay.
- Không tự điền đáp án không chắc chắn.
- Answer Key lưu trong localStorage.
- Có export/import JSON để backup đáp án.

Cách dùng:
1. Giải nén ZIP.
2. Mở index.html.
3. Tab “Đọc đề PDF” để đọc đề.
4. Tab “Answer Key” để nhập đáp án từng Teil.
5. Bấm “Lưu Teil”.
